## Quick Launch:
- **Backend:** `cd know-thyself-ai/backend && uvicorn main:app --reload --port 8000`
- **Frontend:** `cd know-thyself-ai/frontend && npm run dev`
- **Run Backend Tests:** `cd know-thyself-ai/backend && pytest tests -v`
- **Build Frontend:** `cd know-thyself-ai/frontend && npm run build`
